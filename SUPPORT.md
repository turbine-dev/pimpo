# Getting help

- **How do I…?** Start with the [documentation](docs/README.md): the user guide, configuration, routines and connectors.
- **Something is broken.** Open a [bug report](https://github.com/turbine-dev/pimpo/issues/new?template=bug_report.yml) with your version (`pimpo version`) and how to reproduce it. Leave out keys and personal data.
- **A service is missing.** Many need no new code: see [Connectors](docs/CONNECTORS.md), then open a [connector request](https://github.com/turbine-dev/pimpo/issues/new?template=connector_request.yml) if none of the ways works.
- **A security problem.** Report it privately, as [SECURITY.md](SECURITY.md) explains. Never in a public issue.

Pimpo is maintained by volunteers. There is no paid support.
